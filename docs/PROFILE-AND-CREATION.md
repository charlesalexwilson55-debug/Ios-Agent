# Profile choices and local creation

Research choices are retained in the saved chat. Selected sources show a selected state instead of another confirmation button. A rejection applies to the displayed group and starts another bounded search batch, preserving visited pages and query history. Rejected sources are excluded from the displayed report. A batch can still stop when public access fails, budgets are exhausted, or no unused grounded queries remain; it does not promise unlimited discovery or certain identity verification.

Profile labels contain an evidenced name and available, attributed age, location and role. Missing fields remain absent. Ages must be explicitly quoted, are not inferred from dates, and may describe an older source. Selecting a profile is a user choice rather than independent identity verification.

Prose renders links with short, tappable site labels and turns em dash separators into paragraph breaks. Markdown emphasis is rendered rather than shown as markup. Code, exact drafts and ASCII text use fenced, copyable dark glass blocks; their bytes remain unchanged.

The new `create_3d_object` tool makes bounded procedural meshes from up to 32 boxes and spheres, shows an interactive preview, and exports Wavefront OBJ. It is not a trained text-to-3D model, does not sculpt detailed characters, and does not produce textures. `create_image` exposes the existing Apple Image Playground generation route as a model tool, in addition to direct image-request routing. Apple Intelligence and its image model must be available. No paid online generation provider is configured.

Native CI tests cover profile decision persistence and duplicate-group suppression, link and prose formatting, geometry bounds, mesh topology and OBJ export. Device testing is still needed for profile continuation, glass rendering, SceneKit interaction, and Apple image generation availability.
